# DevTrack — Original Approved Prompt
Build a polished, responsive, browser-based project and task tracker for individual developers and freelancers using only HTML, CSS and vanilla JavaScript. It must provide Dashboard, Projects and Tasks views in one HTML document, support CRUD, statuses, priorities, optional due dates, search, filters, project progress, light/dark theme, localStorage persistence and opt-in sample data. Use documented, approval-gated, AI-assisted development. No backend, authentication or framework. Implement in approved batches and verify behavior before marking work complete.

This file captures the approved baseline and should not be casually rewritten. Refer to `REQUIREMENTS.md` for exact behavior and `DECISIONS.md` for later approved changes.
