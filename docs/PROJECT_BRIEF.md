# DevTrack — Project Brief

## Product
**DevTrack** — *Plan. Build. Track. Deliver.*

## Audience
Individual developers and freelancers managing multiple projects and tasks.

## Problem
Project work and task status become difficult to track when spread across notes and informal lists.

## Solution
A responsive, single-browser dashboard with project and task management, progress reporting, filtering and persistent local data.

## Goals
1. Build a genuinely usable personal tool.
2. Demonstrate software planning, AI-assisted development, testing and Git workflow.
3. Produce a presentable portfolio project with explainable code.

## MVP success criteria
- All requirements in `REQUIREMENTS.md` pass their acceptance tests.
- Data survives refresh in the same browser/storage context.
- No critical interaction, data-integrity or accessibility blockers remain.
- README honestly documents localStorage limitations.

## Excluded from MVP
Backend, cloud sync, authentication, collaboration, payments, Kanban drag-and-drop, export/import, notifications, and deployment infrastructure requiring paid services.

## Delivery constraints
Windows, VS Code, Git, GitHub, Codex free plan with limited prompts. No fixed deadline. Prioritize minimal agent turns and manual local validation.
